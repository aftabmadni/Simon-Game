
# 🎮 Simon Game

A classic memory game built with HTML, CSS, and JavaScript. 

## 📌 How to Play

- The game will generate a sequence of button presses.
- You need to repeat the sequence in the correct order.
- The game adds a new step each time you succeed.
- One mistake — and it's game over!

## 🚀 Features

- Fully responsive design
- Interactive animations and sounds
- Keeps track of levels
- Simple and fun UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## 💻 How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/aftabmadni/Simon-Game.git
   ```

2. **Navigate into the project folder**:
   ```bash
   cd Simon-Game
   ```

3. **Open `index.html` in your browser**:
   - You can simply double-click `index.html`, or
   - Use Live Server extension in VS Code.
